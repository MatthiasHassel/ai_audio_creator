# Note: System Requirements
# 1. FFmpeg must be installed on the system:
#    - macOS: brew install ffmpeg
#    - Windows: Download from https://github.com/BtbN/FFmpeg-Builds/releases
#    - Linux: Use package manager (apt install ffmpeg, etc.)
#
# 2. PortAudio is required for PyAudio:
#    - macOS: brew install portaudio
#    - Windows: Included with PyAudio wheel
#    - Linux: apt install portaudio19-dev
#
# Development Setup:
# 1. Install system dependencies first (FFmpeg, PortAudio)
# 2. Create virtual environment: python -m venv venv
# 3. Activate virtual environment:
#    - macOS/Linux: source venv/bin/activate
#    - Windows: venv\Scripts\activate
# 4. Install requirements: pip install -r requirements.txt
#
# Running in Development:
# - Ensure FFmpeg is in PATH
# - Run: python src/main.py
